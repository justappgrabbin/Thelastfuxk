# Synthia Workbench integration

Added an offline, interactive SVG canvas to the existing Android WebView interface, without replacing its chat, computer, files, activity, Linux, Hands or Tasker implementations.

- Draggable components and visible relationships. Labels distinguish implemented components from proposed/unverified Klein integration.
- Boolean AND/OR/XOR planning gate with actual truth-functional evaluation. This is a primitive, not a claim that the Klein model has been integrated.
- Read-only runtime diagnostics using the existing Android `Cynthia.state()` bridge.
- Redesigned styling with a restrained technical dark palette, rather than generic colorful dashboard cards.
- No external JavaScript libraries, network requests, paid API, or GPU requirement. This keeps the app build offline-compatible.
