# Visual app builder status

Added a local, touch-friendly, editable screen builder to the existing computer WebView. Components: heading, text, button, card, input, divider, spacer. Features: selection, property editing, ordering, delete, undo, phone/desktop width, static sandboxed preview, localStorage persistence where enabled, HTML export request. No CDN or paid service.

**Not yet integrated:** model-driven code generation, project filesystem save via Android bridge, drag-positioning, full FlutterFlow features, APK compilation, Qwen weights, or actual Klein backend. Export relies on WebView download support; verify on device. Existing chat, Linux, Hands, Watcher, workbench, files and terminal unchanged.
